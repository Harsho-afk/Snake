# Snake

A terminal-based Snake game written in C using the ncurses library. Enjoy playing the classic Snake game right in your terminal!

## Requirements

- **GCC Compiler**
- **ncurses Library**

## Installation

Clone the repository:
```
git clone https://github.com/Harsho-afk/Snake.git
cd Snake
make
```

## Usage

Run the game from your terminal:
```
./snake
```
